Pertanyaan umum

  
Bagaimana pembayaran dikonfirmasi?
Setelah kamu membayar nominal persis (termasuk kode unik), order dikonfirmasi lewat webhook mutasi atau manual oleh owner. Key tampil di halaman pembayaran begitu terkonfirmasi.

  
Apa itu whitelist IP?
Key hanya bisa dipakai dari IP yang kamu daftarkan. Kalau daftar kosong, key bisa dipakai dari IP mana saja.

  
Kapan limit harian reset?
Setiap pukul 00:00 WIB. Paket unlimited tidak punya batas harian.

  
Key hilang, bagaimana?
Simpan key saat muncul. Kalau paket kamu mendukung custom key, kamu bisa menggantinya di panel Kelola key.
