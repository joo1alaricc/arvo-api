Empat langkah, key langsung aktif

  1. Masuk atau daftar

    Pakai Google atau username. Setiap akun otomatis dapat API key.

  2. Pilih paket & bayar QRIS

    Atur durasi sendiri. Scan QR dari e-wallet atau m-banking apa saja.

  3. Paket aktif otomatis

    Kelola key, whitelist IP, dan riwayat pemakaian di halaman Profil.

  4. Pakai di request

    Kirim header x-api-key. Selesai.

Semua akun boleh beli, member, premium, VIP, maupun owner. Harga dihitung per hari mengikuti durasi yang kamu pilih. Limit direset tiap 00:00 WIB.

Pertanyaan umum

  
Bagaimana pembayaran dikonfirmasi?
Bayar sesuai nominal yang tertera, tanpa biaya admin. Setelah terkonfirmasi, paket di akunmu aktif otomatis dan halaman pembayaran berubah.

  
Apa itu whitelist IP?
Key hanya bisa dipakai dari IP yang kamu daftarkan. Kalau daftar kosong, key bisa dipakai dari IP mana saja.

  
Kapan limit harian reset?
Setiap pukul 00:00 WIB. Paket unlimited tidak punya batas harian.

  
Key hilang, bagaimana?
Simpan key saat muncul. Kalau paket kamu mendukung custom key, kamu bisa menggantinya di halaman Profil.
